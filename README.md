# ❓ FAQ Accordion

A simple and responsive FAQ Accordion built using HTML5, CSS3, and JavaScript.

The FAQ section allows users to click on a question to expand or collapse its answer.

## 🎯 Objective

The main objective of this project is to practice:

- DOM events
- Class manipulation
- Interactive UI components
- Responsive web design

## ✨ Features

- 8 FAQ questions
- Expandable answers
- Collapsible answers
- Smooth opening and closing animation
- Plus icon changes when an answer is opened
- Mobile-friendly layout
- Button-based FAQ questions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
